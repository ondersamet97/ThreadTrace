ThreadTrace

Yalnız bu cihazda saklanır; Threads Saved ile senkronize değildir.

Nasıl kullanılır?
  1. Threads'te kişinin yanındaki simgeye basın, etiket ve not ekleyip kaydedin. Etiketler yan panelde listelenir.
  2. Etikete basarak ilişkili hesapları açın. Threads sayfasında etikete basarak o sayfada yüklü gönderileri filtreleyin.
  3. Ayarlar'da Meta API anahtarınızı kaydedip izin verin. Gönderideki radar düğmesinden metni inceleyip araştırmayı onaylayın.
  4. Takip süresi ve türünü seçin; isterseniz günlük otomatik kontrolü işaretleyin. Kontroller API ücreti doğurabilir.
  5. Veriler cihazda tutulur. Anahtar şifrelenmeden saklanır; kaldırma ve tüm veriyi silme ayarlardadır.
